# 🚀 Como Ativar o README do Perfil no GitHub (3 Minutos)

Este repositório é especial e funciona como a "página inicial" do seu perfil pessoal: `https://github.com/VPariz`.

---

## Passo a Passo

1. Abra o navegador e acesse: [https://github.com/new](https://github.com/new)
2. No campo **Repository name**, digite exatamente: `VPariz`
   * O GitHub exibirá uma caixa verde comemorativa: *"You found a secret! VPariz/VPariz is a special repository that you can use to add a README.md to your GitHub profile."*
3. Selecione a opção **Public** (obrigatório para aparecer no perfil).
4. Marque a caixa de seleção: **Add a README file**.
5. Clique no botão verde **Create repository**.
6. No repositório recém-criado, clique no ícone de lápis ✏️ para editar o `README.md`.
7. Escolha qual estilo você prefere:
   * **Opção 1 (Recomendada - Dinâmica e Tech):** Copie e cole todo o conteúdo do arquivo [`README.md`](./README.md).
   * **Opção 2 (Acadêmica Internacional / Inglês / CERN):** Copie e cole todo o conteúdo do arquivo [`README_ACADEMIC_EN.md`](./README_ACADEMIC_EN.md).
8. Clique em **Commit changes...** e confirme o commit na branch `main`.
9. Acesse [https://github.com/VPariz](https://github.com/VPariz) e veja seu novo perfil no ar!
